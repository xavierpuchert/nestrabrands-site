# nestrabrands.com

Static site for Nestra Brands OÜ, served by GitHub Pages at https://nestrabrands.com.
Plain HTML, CSS and one small script; no build step. Edit, commit, push to `main`, and
Pages republishes in about a minute.

- `index.html` home page, `lumi/index.html` the Lumi page, `404.html`
- `styles.css`, `site.js` (hero tile grid, colour wordmark, step deck)
- `img/` step photos, Lumi icon, social preview image
- `CNAME` keeps the custom domain; do not delete it
